# Third-party material

The staged migration intentionally does not include the MusMus OGG music files or the puzzle-clear WAV from the original project. Their prior instructor permission and/or redistribution rights were not established. Any release that restores these assets needs a separate rights and course-policy review.

The original modified DotGothic16 font is not yet included. Its `.meta` GUID is retained, and the font's license notice is in [licenses/DotGothic16-OFL.txt](licenses/DotGothic16-OFL.txt). DotGothic16 is copyrighted by the DotGothic16 Project Authors and distributed under SIL Open Font License 1.1. The original modification corrected uppercase T alignment and used the internal name Relay Yard Pixel16. The source font can be found at https://github.com/fontworks-fonts/DotGothic16 ; this is not a source for the exact local modification.

The source's Unity packages have their own licenses. The root Apache-2.0 license is not an assertion that third-party materials are Apache-licensed.

The project was developed with substantial ChatGPT assistance across design, coding, debugging, test planning, and writing; the personally reviewed technical report should retain that disclosure.
